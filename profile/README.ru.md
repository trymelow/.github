Плеер для тех, кто много слушает и подпевает. Без баннеров, без роликов между треками, без лимита на пропуски и без текстов за подпиской — только музыка и слова точно в такт.

### Внутри

| Возможность | Что это даёт |
| :--- | :--- |
| **Текст в такт** | Каждое слово загорается в момент, когда его поют, буква за буквой, поверх цветов обложки. |
| **Каталог** | Найди артиста, альбом или трек — или вставь ссылку, и он заиграет через секунду. |
| **Переезд** | Вставь ссылку на плейлист из Spotify, Яндекс Музыки, VK Музыки, SoundCloud или YouTube Music — такой же плейлист появится в медиатеке. |
| **Ссылки** | Трек, альбом или плейлист открывается по ссылке у любого — с Melow и без. |
| **Везде, где ты вошёл** | Лайки, плейлисты и подписки одинаковые на всех устройствах. |
| **Ничего лишнего** | Никакой аналитики, пока ты её не включишь; звук и обложки идут через собственные серверы Melow. Одиннадцать языков. |
